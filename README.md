# front-pocket
Collection of helper scripts that I use for various programs that I use

## Update Obsidian Journal Files

To update journal entries containing _empty_ content, do the following:
- Update the `config.sh` file with the MONTH and YEAR you want to update
  - (OPTIONAL) Update any content in `journal_content` or `prefix_content`
- Run `update_journal_entries.sh`
  - Verify changes by looking at the logs and either accept or deny your changes.
